# Vizuara — Real-World Context-Engineered Agent

## Purpose
End-to-end AI agent that answers queries using real Microsoft Teams data.
Pipeline: Teams scraper → LLM Wiki → Intent Router → Context Window → Confidence Predictor → FastAPI → Streamlit dashboard.

## Stack
- Python 3.11+
- Claude Sonnet 4.6 (claude-sonnet-4-6) via Anthropic SDK
- Microsoft Graph API (Teams data via MSAL)
- FastAPI (REST API)
- Streamlit (dashboard)
- ChromaDB or BM25 (vector/keyword search)

## Folder Structure
```
platform/        Microsoft Teams scraper + connection tester
data/            Scraped JSONL data files (gitignored)
wiki/            LLM knowledge base with search
router/          Intent router + main routing logic
context/         Context window builder
confidence/      Confidence predictor
logs/            Query logs (gitignored)
main.py          FastAPI entry point
dashboard.py     Streamlit dashboard
```

## Environment Variables Required
```
AZURE_CLIENT_ID
AZURE_CLIENT_SECRET
AZURE_TENANT_ID
ANTHROPIC_API_KEY
TARGET_USER_EMAIL
```
Copy `.env.example` → `.env` and fill values. See `AZURE_SETUP.md`.

## Run (Development)
```bash
# Install dependencies
pip install -r requirements.txt

# Step 1: Test Teams connection
python platform/test_connection.py

# Step 1: Scrape Teams data
python platform/teams_scraper.py

# Step 4: Build wiki index
python wiki/llm_wiki.py

# Step 9: Run API
uvicorn main:app --reload

# Step 9: Run dashboard
streamlit run dashboard.py
```

## Key Files
- `platform/teams_scraper.py` — scrapes Teams chats + channel messages
- `platform/test_connection.py` — validates Azure API credentials
- `wiki/llm_wiki.py` — BM25 knowledge base search
- `router/intent_router.py` — classifies query intent via Claude
- `context/context_builder.py` — builds token-budgeted context
- `confidence/predictor.py` — scores response confidence
- `router/main_router.py` — orchestrates full pipeline
- `main.py` — FastAPI endpoints: POST /chat, GET /metrics
- `dashboard.py` — Streamlit UI with confidence scores

## Data Files (auto-generated by scraper)
- `data/chat_history.jsonl` — Q&A pairs from Teams chats
- `data/product_knowledge.jsonl` — substantive messages as knowledge
- `logs/query_log.jsonl` — runtime query logs with confidence + latency
